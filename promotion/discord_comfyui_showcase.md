**MiniMax H3 HACK Studio** — a Windows app for running MiniMax H3 locally
without touching ComfyUI's node graph.

Point it at your ComfyUI backend, then generate T2V / I2V / R2V through a
simple form (prompt, aspect ratio, duration, resolution). It also has:

- One-click radio-button selection for quantization (int8/w4a8), Turbo-family
  LoRAs, and VAE acceleration — each option explains its own tradeoffs inline
- Multi-LLM prompt rewriting (xAI / OpenAI / Anthropic / Gemini) built in
- A job queue with inline video playback

Still in beta (v0.9b), self-contained Windows installer, no source published
(compiled only). Feedback welcome!
